# Calculator

A simple calculator web application with separated UI and logic, plus automated tests using Vitest.

## Project Structure

- `calculator.html` - Application markup
- `calculator.css` - Styling
- `calculator.js` - DOM/event handling
- `calculator-logic.js` - Core calculator logic
- `tests/` - Unit and DOM tests

## Prerequisites

- Node.js 20.19.0+
- npm

## Install Dependencies

```bash
npm install
```

## Run Tests

```bash
npm test
```

## Run in Browser

Open `calculator.html` in your browser.

## Notes

- Test configuration is in `vitest.config.js`
- Test guidance is documented in `TESTING.md`
- Styling guidance is documented in `STYLING_INSTRUCTIONS.md`
